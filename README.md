# FitBuddy – AI Fitness Plan Generator

FitBuddy is an AI-powered web application that generates personalized 7-day fitness plans using Google Gemini and FastAPI.

## Features

- Personalized fitness plans
- Workout recommendations
- Nutrition and recovery tips
- Different fitness goals
- Adjustable workout intensity
- AI-powered recommendations

## Technologies Used

- Python
- FastAPI
- Google Gemini
- HTML
- CSS
- JavaScript
- SQLite

## Project Goal

The goal of FitBuddy is to provide users with a simple AI-based fitness planning assistant.
